<research_summary>
The CAMARA Call Forwarding Signal API is real and live on many networks worldwide (about 140 API instances launched across 85 networks), but it is still pre-1.0 (v0.3.0). That gives carriers (CTIA) a ready answer: "use the existing offering." It also means the FS-ISAC attestation spec could stall or get folded into CAMARA rather than become a US standard any time soon. CAISI already runs cyber assessments of open-weight models: GLM-5.3 was rated "the most cyber-capable open-weight model released to date," and DeepSeek V4 was rated about 8 months behind the frontier. So the open-weight docket will be heated, and any Anthropic filing will be read politically, especially one that includes harness materials CAISI asked not to be published. RAND's own recent methods work on human-AI RCTs covers clustering and spillover bias, which suggests its reviewers could raise more concerns even after the script is hash-locked. Credit-union core processors run slow vendor-risk and change-control cycles, so going from sandbox to production in one month is unlikely. Overall, this month's main risks are more slips, and filings whose content or timing gets framed badly. A dramatic collapse is unlikely.
